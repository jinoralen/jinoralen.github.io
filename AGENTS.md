## Development

When starting the dev server, use background mode:

```
astro dev --background
```

Manage the background server with `astro dev stop`, `astro dev status`, and `astro dev logs`.

Before finishing a change, run:

```
pnpm format      # Prettier: tabs, single quotes, 120 columns (format:check only reports)
pnpm typecheck   # astro check; needs TypeScript 6, it refuses to run on 7
pnpm build
```

Site content lives in `src/data/site.ts`. Work history mirrors the CV (`../CV/cv/experience.typ`); keep claims in sync with it.
